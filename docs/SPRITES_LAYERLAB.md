# Sprites Layer Lab — como recortar peças novas (9-slice)

Origem: pack **GUI Pro – Casual Game** (Layer Lab, Unity Asset Store, licença dos dois sócios).
A biblioteca completa fica em `assets/layerlab/casual/` (se o repo for privado) ou é
distribuída por fora e extraída nessa mesma pasta (gitignored). Peças em uso vão para
`web/public/ui/` com nome curto e viram classes em `web/src/index.css`.

## Receita
1. Escolher o PNG em `Components/{Button,Frame,Popup,Label,Slider,UI_Etc,IconMisc}`.
2. Pegar a fatia do Unity na tabela abaixo (`spriteBorder` = **x:esq, y:baixo, z:dir, w:cima**).
   Em CSS a ordem é **top right bottom left** → `w z y x`.
3. Se `esq+dir == largura` ou `cima+baixo == altura`, **reduzir 1–2 px** (o miolo não pode ter 0 px
   no CSS — o Unity tolera, o navegador não desenha nada).
4. Classe: `.minha-peca { border-style: solid; border-color: transparent; border-image: url(/ui/x.png) T R B L fill; border-width: <fatias × escala>px; }`
   Escala típica: 1/3 para botões (64×195), 1/2 para painéis.
5. Materiais só-textura do pack têm o miolo sólido — `fill` preenche; ícones vão como `<img>`.
